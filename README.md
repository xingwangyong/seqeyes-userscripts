# Open in SeqEyes — GitHub Userscript

A Tampermonkey userscript that adds an **Open in SeqEyes** button on GitHub, letting you view `.seq` MRI pulse sequence files in the [SeqEyes Web Viewer](https://bughht.github.io/seqeyes_plugin/).

## Features

- **Directory listing**: Adds a blue **SeqEyes↗** button next to every `.seq` file in a GitHub repository tree view.
- **File view**: Adds an **Open in SeqEyes** button beside the Raw button when browsing a single `.seq` file.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) for your browser.
2. Click **[Install Script](https://raw.githubusercontent.com/xingwangyong/seqeyes-userscripts/main/open-seq.user.js)** — Tampermonkey will open an installation prompt.
3. Click **Install**.

## Usage

Navigate to any GitHub repository containing `.seq` files. The button appears automatically within a few seconds of the page loading.

## Requirements

- Tampermonkey v4.0+
- Chrome, Firefox, Edge, or Safari
